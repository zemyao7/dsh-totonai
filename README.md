# dsh-totonai

把 ToTonAI AI 中转站接进 DeepSeek Harness 的插件:账号登录、65 个主流模型直连、站内扫码充值开通会员。

> 支持 **GPT / ChatGPT / Claude / Gemini / DeepSeek / 豆包 / Grok / GLM** 等 65 个主流模型。
> 在 DSH 插件市场搜索栏输入 `GPT`、`Claude`、`DeepSeek`、`Gemini` 或 `ToTonAI` 都能搜到本插件。

- **账号制,不接触上游 Key**:在 DSH **设置 → ToTonAI** 面板里用账号密码登录(或填插件配置),插件自动登录换令牌,上游 API Key 永远不会出现在插件包或对话里。
- **完整复制站点体系**:与 www.toton.pro 相同的模型目录、会员档位与计费口径。
- **模型按档位标记**:模型选择器里始终显示全部模型,当前档位调不了的会在名字后面标上「需升级」,一眼就能看出升级能解锁什么。
- **图形面板**:设置在 DSH 设置页里,登录/注册、会员状态、选档位出收款二维码、"我已付款"申报,都不用跳网页。
- **站内充值**:对话里说"帮我充值",模型生成收款码订单,扫码按金额付款并备注用户名,付款后一句话完成申报,站长核对后开通。

## 功能

| 能力 | 说明 |
| --- | --- |
| 图形面板 | 设置 → ToTonAI:登录 / 注册、会员状态(含本月额度与加油包余额)、选档位与月年卡或加油包出收款码、"我已付款"申报、刷新状态 |
| 模型接入 | OpenAI / Anthropic / Google / DeepSeek / 豆包 / Grok / GLM 等 65 个文本模型,全部可见,当前档位调不了的标「需升级」 |
| 账号注册 | `totonai_register` 在对话里直接注册站点账号,不用打开网页 |
| 账号登录 | 配置账号密码后自动换取令牌,令牌 7 天有效,过期自动静默续期 |
| 自动重试 | 令牌失效(401)时自动重新登录并重试本次请求 |
| 充值开通 | `totonai_recharge` 生成会员收款码订单(价格实时读取站点配置)、`totonai_topup` 生成加油包订单、`totonai_pay_claim` 提交付款申报 |
| 额度查询 | `totonai_pay_status` 读站点实时数据,返回本月额度、已用、剩余、加油包余额与到期天数 |
| 会员档位 | Go / Plus / Pro Max,月卡与年卡两种周期;另加油包 4 档(只加额度不加权限) |

## 安装

### 从插件市场安装(推荐)

在 DSH「插件 → 插件市场 → 发现」搜索 `totonai` 或 `ToTonAI`,点安装,重启 DeepSeek Harness。

### 命令行安装

```bash
# npm 源
dsh plugin --profile desktop add dsh-totonai

# GitHub 源
dsh plugin --profile desktop add zemyao7/dsh-totonai
```

`--profile` 换成自己的 profile 名:桌面客户端默认是 `desktop`,浏览器版通常是 `web`。

### 本地安装(开发/自用)

```bash
# 在插件目录打包
npm pack

# 在 DSH 里安装本地包
dsh plugin --profile desktop add ./dsh-totonai-0.1.5.tgz
```

## 配置

装好之后**不用改配置**,直接进 DSH **设置 → ToTonAI** 面板:

1. 没有账号 → 点"注册新账号",填用户名(3-32 位字母/数字/下划线)和密码(≥6 位),注册成功自动登录。
2. 有账号 → 直接登录。
3. 登录后面板显示用户名和当前档位。
4. 想开通或续费 → 选 Go / Plus / Pro Max、月卡或年卡、微信或支付宝,点"生成收款码",面板里直接显示二维码图片。
5. 扫码付对应金额,**备注里写你的用户名**,回来点"我已付款";站长核对后开通,再点"刷新状态"即可看到档位变化。

账号密码只保存在本机 `~/.dsh-totonai/creds.json`(权限 600),不写进任何日志或对话内容。

也可以继续用插件配置(可选,优先级高于面板):

| 字段 | 说明 |
| --- | --- |
| 站点地址 baseURL | 默认 `https://www.toton.pro`,一般不用改 |
| 账号 username | 留空即可,面板登录时会自动写入 |
| 密码 password | 留空即可 |
| 请求超时 | 非流式请求超时秒数,默认 180 |

配置完成后重启,在模型选择器里即可看到 `ToTonAI` 的 65 个模型;你当前档位能用的正常显示,不能用的名字后面带「需升级」,充值开通后刷新即可去掉标记。

## 使用

### 还没有账号?

两种方式,选一个:

- **面板注册(推荐)**:设置 → ToTonAI → "注册新账号",填用户名密码,注册完自动登录,马上能用。
- **对话注册**:说"帮我注册一个 ToTonAI 账号,用户名 demo_01,密码 123456",模型调用 `totonai_register` 完成注册,再去面板登录即可。

### 日常使用

1. 新会话选择任意 ToTonAI 模型(如 `deepseek/deepseek-v4-pro` 或 `openai/gpt-5.4`)。
2. 正常对话。
3. 需要开通会员时,直接说:

> 帮我充值 Plus 月卡

模型会调用 `totonai_recharge` 返回金额、订单号和收款码链接;按金额付款,备注写上你的用户名,回来说"已付款",模型调用 `totonai_pay_claim` 把申报提交给站长。站长核对到账后开通,一般 5 分钟内生效;之后说"查一下会员状态",模型读取你的账号确认档位。

> 说明:站点使用个人收款码,没有自动回调,开通由站长人工确认,这是当前设计的正常流程,不是故障。

> **WorkBuddy 用户看这里** → 直接进 [workbuddy/](workbuddy/)，双击 `.cmd` 即可，不用点「添加模型」、不用填 JSON。
> 本插件、以及 WorkBuddy 接入包，都需要 **www.toton.pro** 账号（免费注册，注册后在「我的 API Key」里复制 Key）。

## 会员档位与额度

| 档位 | 显示名 | 月卡 | 年卡 | 每月 token 额度 |
| --- | --- | --- | --- | --- |
| `entry` | Go | ¥27 | ¥307 | 350 万 |
| `pro` | Plus | ¥77 | ¥847 | 1000 万 |
| `ultimate` | Pro Max | ¥177 | ¥2077 | 2300 万 |

价格与额度实时读取站点配置,以面板显示为准。

**额度怎么看**:设置页 ToTonAI 面板的账号卡片里会显示「本月额度 已用 x / 共 y,剩 z token」「加油包余额 n token(多少天后到期)」;也可以在对话里说"查一下我还剩多少额度",模型调用 `totonai_pay_status` 读站点实时数据。

**额度用完会怎样**:超过当月额度后,站点会直接返回 402「本月额度已用完」,不会继续扣费。想继续用有两种办法:等下一个自然月自动重置,或者加购加油包。

## 加油包(只加额度,不加模型权限)

| 档位 | 价格 | 到账 token | 有效期 |
| --- | --- | --- | --- |
| `topup_10` | ¥10 | 120 万 | 90 天 |
| `topup_30` | ¥30 | 360 万 | 90 天 |
| `topup_70` | ¥70 | 850 万 | 90 天 |
| `topup_160` | ¥160 | 2000 万 | 90 天 |

加油包只叠加 token 额度,**不会提升模型权限**(免费档买了加油包仍然只能用 10 个免费模型)。扣减顺序是先扣当月额度,额度用尽后再扣加油包。已过期账号需要先续包月才能买加油包。

## 免费体验额度

新注册账号是免费档:可用 10 个免费模型,并赠送 **30 万 token** 一次性体验额度,用完为止、不按月重置。同一设备或同一出口 IP 24 小时内只能领一次,重复注册只给账号不给额度。

## 说明

- 生图模型暂不接入 DSH 对话流,请继续在 ToTonAI 网页端使用生图功能。
- `openai/gpt-5-mini` 在模型选择器里标着「仅网页可用」:该模型一带工具调用就会被上游拒绝(HTTP 400),所以在 DSH 里用不了,但网页端纯聊天正常。换成 `doubao-seed-2.0-pro`、`deepseek/deepseek-v4-flash` 等即可。
- 令牌仅保存在进程内,重启后自动重新登录;账号密码只写在本机 `~/.dsh-totonai/creds.json`,不写进任何日志或对话内容。
- 插件仅与你的 ToTonAI 站点通信,所有请求都带 DeepSeek Harness 归属标识。
