# dsh-totonai

把中转站接进 DeepSeek Harness \ WorkBuddy的插件。

> 支持 **GPT / ChatGPT / Claude / Gemini / DeepSeek / DouBao / Grok / GLM** 等多家主流模型。
> 不封号、不翻墙、可直充。

## 安装

### 方式一:在 DSH 里添加插件(推荐)

1. 打开 DeepSeek Harness,进「插件」页
2. 点「添加插件」,输入 `dsh-totonai`
3. 点安装,按提示重启 DeepSeek Harness
4. 进「设置 → ToTonAI」面板,登录或注册

搜不到时可以换成 `ToTonAI`、`totonai`,或者搜 `GPT`、`Claude`、`DeepSeek`——这几个词都在插件描述里。

### 方式二:WorkBuddy 接入

1. 打开 www.toton.pro 注册账号
2. 左下角用户一栏,点「我的 API Key」
3. 最下方点「下载 WorkBuddy 接入包(已含我的 Key)」
4. 打开 WorkBuddy → 设置 → 模型,就能用


## 配置

装好之后**不用改配置**,直接进 DSH **设置 → ToTonAI** 面板:

1. 没有账号 → 点"注册新账号",填用户名(3-32 位字母/数字/下划线)和密码(≥6 位),注册成功自动登录。
2. 有账号 → 直接登录。
3. 登录后面板显示用户名和当前档位。
4. 想开通或续费 → 选 Go / Plus / Pro Max、月卡或年卡、微信或支付宝,点"生成收款码",面板里直接显示二维码图片。
5. 扫码付对应金额,**备注里写你的用户名**,回来点"我已付款";站长核对后开通,再点"刷新状态"即可看到档位变化。

账号密码只保存在本机 `~/.dsh-totonai/creds.json`(权限 600),不写进任何日志或对话内容。


## 使用

### 还没有账号?

- **面板注册**:设置 → ToTonAI → "注册新账号",填用户名密码,注册完自动登录,马上能用。

### 日常使用

1. 新会话选择任意 ToTonAI 模型(如 `deepseek/deepseek-v4-pro` 或 `openai/gpt-5.4`)。
2. 正常对话。
> 说明:站点使用个人收款码,没有自动回调,开通由站长人工确认,这是当前设计的正常流程,不是故障。

## 说明

- `openai/gpt-5-mini` 在模型选择器里标着「仅网页可用」:该模型一带工具调用就会被上游拒绝(HTTP 400),所以在 DSH 里用不了,但网页端纯聊天正常。换成 `deepseek/deepseek-v4-flash` 等当前开放的文本模型；模型目录会随站点更新。
- 令牌仅保存在进程内,重启后自动重新登录;账号密码只写在本机 `~/.dsh-totonai/creds.json`,不写进任何日志或对话内容。
- 插件仅与你的 ToTonAI 站点通信,所有请求都带 DeepSeek Harness 归属标识。
